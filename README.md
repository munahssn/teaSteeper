# Tea Steeper

A self made pixel-art tea timer. Pick a tea, and wait for the counter while it steeps.

**Live:** https://munahssn.github.io/teaSteeper/

## Teas

| Tea    | Steep time |
|--------|------------|
| Black  | 3 min      |
| Green  | 2 min      |
| Herbal | 4 min      |

## Running it

**Web:** open `index.html` in a browser. No build step or dependencies.

**Desktop (Python):** there's also a Tkinter version.

```
pip install -r requirements.txt
python main.py
```

## Files

- `index.html`, `style.css`, `script.js` — web version
- `main.py` — desktop version
- `sprites/` — pixel art used by both
